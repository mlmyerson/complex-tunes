What this graph means — and how to explore it

Path(t) = [ E(t), E(t − τ), E(t − 2τ) ]

This is a three-dimensional delay-coordinate portrait of measured audio features. It is inspired by techniques used to study dynamical systems. A recording is not assumed to be a low-dimensional autonomous system: this picture alone does not establish chaos, a strange attractor, or the equations that generated the music. Its shape depends on the measured feature, delay, smoothing, and normalization.

Analysis samples energy 50 times per second using centered 2,048-sample Hann-windowed FFTs. Band powers are averaged across recorded channels before conversion to decibels, avoiding stereo phase cancellation. The left/right option measures each channel’s full-spectrum energy. Mono files have one channel trace. Each feature has a −80 dB floor, is exponentially smoothed, then independently centered and scaled by its whole-recording standard deviation (with a minimum scale of 1 dB). Relative shapes can be compared; plotted size does not compare absolute loudness between bands.

The first 2τ seconds have no complete delay vector and are omitted. Scrubbing rebuilds the path from the analyzed recording. Complete-song mode includes the entire trajectory, with a glowing point at the current playback time. Hidden traces affect only the drawing; you always hear the original recording. The three axes use standardized units; the camera fits all features automatically.

Try the demo, then change τ from 0.20 to 0.50 seconds. Pause on a phrase and rotate the graph. Load your own song and look for differences between a verse, a chorus, and a quiet passage. Use one visible band to make loops easier to inspect.

Inside the instrument — equations, mappings, and experiments

dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = xy − βz

The original path starts at (0.1, 0, 0) and uses fourth-order Runge–Kutta integration with a fixed time step of 0.005. Speed changes how quickly simulation time passes. The view shows x horizontally and z vertically; each color identifies one path. The coordinate readout follows the original path. It fits the growing trajectory automatically.

This is parameter sonification: the coordinates control a synthesizer, rather than being played directly as an audio waveform. Pitch = base frequency × 2^(x × pitch span / 24), clamped to 40–2400 Hz. Stereo pan = tanh(y / 20). Filter cutoff = 180 × 2^(clamp(z, 0, 80) / 12) Hz, capped at 9000 Hz. A quiet second oscillator sits one octave below. Audio parameters are smoothed to reduce clicks.

Try the classic settings (σ = 10, ρ = 28, β = 8/3), then lower ρ to 15 and reset. Listen as the trajectory eventually settles toward a fixed point. Change one parameter at a time to hear its effect. The same starting state and settings reproduce the same path; chaos is deterministic, even when its long-term motion is hard to predict.

Add up to six simultaneous paths with different initial x offsets. Each colored path has its own oscillator pair, filter, and stereo position; the voice type is shared. Mute paths to compare them. The mix is normalized by the number of unmuted voices. New paths start at their initial state when added; reset aligns all paths at simulation time zero. Identical offsets retrace the same trajectory when reset together. Reset returns every path to its initial state and clears the trails. Pause holds both the path and its current tone. Stop listening mutes the instrument while the visual simulation continues. Sound requires a tap and stays off when the page first opens.
